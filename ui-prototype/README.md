# NapNav — Trip Alarm UI prototype

ต้นแบบนี้ใช้คุยเรื่องลำดับข้อมูล น้ำเสียง และสถานะหลักก่อนเริ่มเขียน SwiftUI จริง

เปิด `index.html` ในเบราว์เซอร์ แล้วกดเลือกหน้าจอด้านซ้ายได้ 4 สถานะ:

1. เลือกจุดหมาย
2. ตั้งค่าการเตือน
3. กำลังเดินทาง
4. เตรียมตัวลง

## สิ่งที่ต้องช่วยกันตัดสิน

- รอบนี้ใช้ระยะถึงจุดหมายเป็นข้อมูลหลัก ส่วน ETA เก็บไว้ทดลองในรอบถัดไป
- คำว่า “เปิดเตือนไว้แล้ว” ให้ความมั่นใจพอไหม
- “เตรียมตัวลง” ใช้ได้กับรถสาธารณะทุกประเภทหรือควรใช้ “ใกล้ถึงแล้ว”
- โทน Native transit utility ควรเป็นค่าเริ่มต้น หรือให้ตามการตั้งค่าของเครื่อง

หน้าตั้งค่ามีระยะสำเร็จรูป 500 เมตร, 1 กิโลเมตร และ 2 กิโลเมตร หากเลือก “กำหนดระยะเอง” จะปรับได้ตั้งแต่ 100 เมตรถึง 5 กิโลเมตร วงรอบจุดหมายบนแผนที่จะขยายหรือหดตามระยะที่เลือกทันที

## ขอบเขต

นี่เป็น visual prototype เท่านั้น แผนที่และสถานะทั้งหมดเป็นข้อมูลจำลอง ยังไม่ได้เชื่อม Core Location หรือ Notification
