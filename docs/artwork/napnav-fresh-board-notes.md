# NapNav — บอร์ดเริ่มใหม่ (ขาวดำ)

แนวคิด 12 แบบนี้ไม่ใช้หมุด ตัว N เส้นทาง หรือธงจากรอบก่อน. ทุกแบบเป็น SVG เวกเตอร์แยกไฟล์ใน `concepts/napnav-fresh-*.svg`; ภาพรวมอยู่ใน `napnav-fresh-board.svg` และ `napnav-fresh-board.png`. ยังเป็น thumbnail exploration ไม่ใช่โลโก้สุดท้าย.

| หมายเลข | ความคิดตั้งต้น | อ่านครั้งแรก / จุดต้องระวัง |
| --- | --- | --- |
| 01 Arrival halo | วงระยะโอบจุดที่ใกล้ถึง | รูปจำง่าย แต่คล้ายสัญญาณหรือ Wi-Fi ต้องแก้ให้เป็นเอกลักษณ์ |
| 02 Sleep / wake | จากพักสู่การปลุก | สื่อการนอนชัด แต่พระจันทร์กับเครื่องหมายบวกเป็นภาษาภาพทั่วไป |
| 03 Threshold | ผ่านขอบเขตที่ตั้งไว้ | สื่อ “เข้าเขต” ได้ แต่ส่วนกลางอาจอ่านเป็นปุ่มลบ |
| 04 Horizon | ใกล้ถึงขอบฟ้า | อบอุ่น แต่ใกล้ไอคอนพระอาทิตย์ขึ้นทั่วไป |
| 05 Chime | เสียงเตือนเมื่อถึง | อ่านเป็นกระดิ่งทันที แต่ generic และเส้นข้างเดียวทำให้ไม่สมดุล |
| 06 Landing | การแตะถึงพื้นที่ | เบาและเป็นมิตร แต่ความหมายยังไม่ชัดโดยไม่มีชื่อ |
| 07 Orbit | จุดเคลื่อนเข้าเขต | มีการเคลื่อนไหว แต่คล้ายดาวเคราะห์มากกว่าการนำทาง |
| 08 Open eye | ตื่นเมื่อถึง | อ่านเป็นตา; อาจไม่ตรงกับประสบการณ์นอนพักของแอพ |
| 09 Safe pocket | จุดหมายอยู่ในพื้นที่ที่โอบรับ | รูปทรงจำง่าย แต่อาจอ่านเป็นโล่หรือใบหน้ายิ้ม |
| 10 Countdown | เวลาและเหตุการณ์ใกล้ถึง | อ่านชัด แต่คล้ายแอพจับเวลาทั่วไป |
| 11 Distance | ระยะด้านข้างกำลังหดเข้าหาจุดกลาง | สมดุลและย่อได้ แต่คล้ายสัญญาณวิทยุ |
| 12 Dawn gate | ช่องเปิดเมื่อถึง | รูปทรงเข้มและชัด แต่เครื่องหมายบวกอาจสื่อสุขภาพ |

## ทิศทางที่น่าลองต่อ

01, 03, 09 และ 11 มีแกนความคิดต่างกันพอให้พัฒนาเพิ่ม. ต้องทำรอบลดความคล้ายไอคอนทั่วไปและตรวจบน Home Screen จริงก่อนคัดเป็น finalist. สี Forest/Linen ยังไม่ถูกใช้ในรอบนี้ เพื่อให้รูปทรงเป็นตัวตัดสิน.
