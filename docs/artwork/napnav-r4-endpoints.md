# NapNav R4 — meaningful route endpoints

อัปเดต 26 กันยายน 2026; SVG concept สำหรับรับความเห็น

ผู้ใช้ชอบเส้นทางโค้งของ R4 แต่จุดกลมต้น/ปลายไม่สื่อความหมาย รอบนี้คงหมุดและเส้นทางเดิม ตัดจุดกลมต้นทาง และเปลี่ยนปลายทางเป็นสัญลักษณ์ที่บอกหน้าที่

| แบบ | ปลายเส้นสื่ออะไร | จุดแข็ง | ความเสี่ยง |
| --- | --- | --- | --- |
| R4A Arrow | ทิศทางการเดินทางไปต่อจนถึงเป้าหมาย | เรียบ อ่านเป็นเส้นทางที่เคลื่อนที่ | ลูกศรชี้ขึ้นอาจสื่อ navigation ทั่วไปมากกว่าการแจ้งเตือน |
| R4B Destination flag | จุดหมายที่เลือกไว้ | เชื่อมความหมายของหมุดกับการถึงจุดหมายชัดกว่า | ธงมีรายละเอียดมากกว่าลูกศร และต้องเก็บขนาดให้ยังอ่านได้เมื่อย่อ |

ทั้งคู่ไม่มีวงกลมตกแต่ง; SVG ใช้รูปทรงเวกเตอร์ self-contained. ส่งออกดูที่ 512, 32, 16 px และขาวดำชั่วคราวแล้ว; เส้น N กับหมุดยังอยู่ในทุกขนาด แต่สัญลักษณ์ปลายทางจะเล็กมากที่ 16 px. งานนี้ยังไม่ใช่ final AppIcon หรือผลบน Home Screen จริง

**ข้อเสนอ:** R4B ตอบข้อสังเกตเรื่องความหมายของปลายทางได้ตรงกว่า; R4A มีความเรียบกว่า. ให้ผู้ใช้เลือกสัญลักษณ์ก่อนเก็บรายละเอียด optical alignment
