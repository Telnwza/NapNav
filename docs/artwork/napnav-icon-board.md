# NapNav icon concept board — 25 September 2026

## Brand brief

- **Product promise:** เลือกจุดหมาย เริ่มทริป แล้วรับการเตือนเมื่อเข้าใกล้จุดหมาย
- **Audience:** ผู้เดินทางทั่วไปที่ต้องการพักหรือทำอย่างอื่นระหว่างทาง
- **Visual tension:** สงบและไว้ใจได้ ขณะเดียวกันต้องเห็นสัญญาณเตือนชัด
- **Primary use:** iPhone app icon; SVG เป็น source master ที่ส่งออกขนาดอื่นภายหลัง
- **Assumptions:** ไม่มีคำบน icon; ยังไม่ผูกแบรนด์กับรถเมล์/รถไฟ; สีทดลองเปลี่ยนได้
- **Category check:** รูปหมุดซ้อนนาฬิกาหรือกระดิ่งพบในแอพ location alarm หลายตัว จึงไม่ใช้เป็นทิศทางหลัก

## Public-method design lenses

- **Idea-led simplicity (Paul Rand):** อธิบายแนวคิดได้ในหนึ่งประโยคและจำ silhouette ได้
- **System discipline (Massimo Vignelli):** รูปทรงและสีต้องนำไปใช้กับหน้าจอ/สื่ออื่นได้
- **Presence (Paula Scher):** ไอคอนต้องมีบุคลิกเมื่ออยู่ท่ามกลางไอคอนแอพอื่น

ทั้งสามข้อใช้เป็นเกณฑ์วิจารณ์ ไม่ได้เลียนแบบผลงานของนักออกแบบคนใด

## Three directions

| Concept | Idea and geometry | Palette | One-color behavior | Main risk |
| --- | --- | --- | --- | --- |
| A — Arrival zone | เส้นทางโค้งตัดวงเขตและหยุดที่จุดกึ่งกลาง | Ink `#102A3B`, ivory `#F3F4E9`, mint `#73D5C5`, amber `#F6A65F` | วง เส้น และจุดรวมเป็น silhouette เดียวได้ | อาจอ่านเป็นแว่นขยายเมื่อเล็ก |
| B — Route N | ตัว N เป็นเส้นต่อเนื่อง ปลายบนขวาคือจุดหมาย | Ivory `#F3F1E8`, ink `#173E50`, terracotta `#E28A58` | N กับจุดหมายยังอ่านได้ด้วยสีเดียว | อาจสื่อการเตือนไม่ชัดโดยลำพัง |
| C — Pin path | หมุดขนาดใหญ่มี N เป็นช่องว่างภายใน | Deep teal `#143C41`, pale mint `#E7F0DF`, amber `#EAA165` | หมุดและช่อง N ยังอยู่ได้ด้วยสองค่าน้ำหนักขาวดำ | หมุดยังเป็นรหัสภาพที่พบทั่วไป |

## Board critique

| Lens | A — Arrival zone | B — Route N | C — Pin path |
| --- | --- | --- | --- |
| Idea | เข้าใจการเข้าเขต แต่ต้องมองเส้นทาง | จำรูป N ได้ทันที; ความหมายมาจากชื่อ | เข้าใจแผนที่และชื่อพร้อมกัน |
| System | วงเขตและเส้นทางต่อยอดเป็น motion ได้ | N เป็นฐาน wordmark/brand pattern ได้ | รูปทรงหมุดใช้ต่อใน map UI ได้ |
| Presence | สีสวยแต่รูปคล้าย search/target | พื้นสว่างต่างจากแอพแผนที่ส่วนใหญ่ | พื้นเขียวเข้มและหมุดใหญ่เด่น |

**First recommendation:** B และ C เป็นสองทิศทางที่ควรให้ผู้ใช้เลือกต่อ. B มีความเป็นแบรนด์กว่า; C สื่อหมวดแอพเร็วกว่า. A ถูกตัดจาก shortlist เพราะภาพขนาดเล็กและภาพสีเดียวอ่านคล้ายแว่นขยาย. ไม่ได้สรุปว่าแบบใดผ่านการตรวจความคล้ายทางเครื่องหมายการค้า
