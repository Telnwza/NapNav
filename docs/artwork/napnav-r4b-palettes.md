# NapNav R4B — two-color palette study

อัปเดต 26 กันยายน 2026; SVG concepts สำหรับเลือกสี ยังไม่ใช่ final AppIcon

รูปทรงหมุด เส้นทาง N และธงเหมือนกันทุกไฟล์ แต่ละแบบใช้สองสีเท่านั้น: สีหนึ่งเป็นพื้นกับเส้นทาง/ธง อีกสีเป็นตัวหมุด ทำให้เทียบสีได้โดยไม่ปนความต่างของรูปทรง

| แบบ | คู่สี | อารมณ์ | Contrast ระหว่างสองสี |
| --- | --- | --- | ---: |
| P1 Forest / Linen | `#164449` + `#EEE7D8` | สุขุม อบอุ่น ใกล้ R4B ที่เลือก | 8.72:1 |
| P2 Midnight / Ice | `#102E48` + `#D1EFF2` | เย็น คม ดูเป็นแอพนำทาง | 11.51:1 |
| P3 Plum / Apricot | `#382B4F` + `#FFD8B3` | มีบุคลิก ต่างจากโทนฟ้าของหมวดนี้ | 9.67:1 |
| P4 Clay / Cream | `#A8493A` + `#F7E9D0` | อบอุ่น เป็นมิตร | 4.76:1 |
| P5 Pine / Lime | `#153E35` + `#DAEF9F` | สดและเด่นบน Home Screen | 9.49:1 |

## ตรวจแบบ

- ตรวจ XML ทุกไฟล์ และตรวจด้วยสคริปต์ว่า path geometry เหมือนกันทุกแบบพร้อมมีสีเพียงสองค่า
- ส่งออกภาพตรวจที่ 512, 64, 32 และ 16 px; หมุด เส้นทาง และธงยังแยกได้ในภาพย่อที่ดูด้วยตา
- สีทั้งห้าเป็นตัวเลือกทดลอง; ยังไม่ตรวจในบริบท Home Screen จริงทั้ง Light/Dark และภาพพื้นหลังหลายแบบ

**ข้อเสนอสำหรับคัดต่อ:** P1 รักษาความรู้สึก R4B เดิมดีที่สุด, P2 ชัดที่สุดเชิง contrast, P3 ให้บุคลิกที่ต่างจากแอพแผนที่โทนฟ้าทั่วไป. หลังเลือกสี จึงทำ optical review ของธง/ระยะห่างขอบ แล้วสร้าง SVG master และ AppIcon package

## P1 Light / Dark pair

ผู้ใช้เลือก Forest / Linen จึงเพิ่ม `concepts/napnav-r4b-p1-forest-linen-dark.svg`. Light ใช้พื้น linen กับหมุด forest; Dark สลับเป็นพื้น forest กับหมุด linen โดยให้เส้นทาง/ธงเป็นสีเดียวกับพื้นในแต่ละแบบ. รูปทรงและคู่สี `#164449` / `#EEE7D8` เหมือนกันทุกจุด; contrast ของทั้งคู่เท่ากันที่ 8.72:1. Dark SVG เป็นตัวเลือก artwork ยังไม่ได้ติดตั้งเป็น dark appearance ใน Xcode
