# NapNav — new logo exploration

วันที่ 26 กันยายน 2026

## Brief ที่ใช้

NapNav ช่วยผู้ใช้เลือกจุดหมาย เดินทางโดยล็อกจอ และเตือนเมื่อใกล้ถึง. โลโก้ต้องอ่านเป็นแอพนำทางที่น่าเชื่อถือและสบายตา ใช้บน Home Screen เป็นหลัก. ชื่อ NapNav เปิดทางให้ใช้ตัว N แต่ไม่จำเป็นต้องยัดสัญลักษณ์ทุกอย่างไว้พร้อมกัน. Forest/Linen เป็นคู่สีที่ผู้ใช้ชอบ; รอบนี้ตัดสีออกเพื่อคัดรูปทรง.

## แนวคิด

| แบบ | แกนความคิด | สิ่งที่เห็น | ความเสี่ยงจากการตรวจภาพย่อ |
| --- | --- | --- | --- |
| 01 Shelter | หมุดโอบเส้นทาง | หมุดทึบและ N ช่องว่าง | อ่านชัดสุด แต่ใกล้รูปแบบหมุดทั่วไป ต้องสร้างเอกลักษณ์ในจังหวะ N |
| 02 Loop | เส้นทางวนกลับสู่จุดหมาย | หมุดเส้นเปิดกับ N | เส้นชนกันและปลายล่างดูเหมือนขาด; ไม่ควรพัฒนาต่อในรูปนี้ |
| 03 Arrival | N ถึงประตูจุดหมาย | หมุดกับเส้น N ที่จบในมุมบน | ส่วนมุมบนดูเหมือนชิ้นส่วนแปะและหายเมื่อย่อ; ไม่ควรพัฒนาต่อในรูปนี้ |
| 04 Ribbon | เส้น N กลายเป็นธง | N เดี่ยวและธง | มีบุคลิกกว่าแต่ขาดรหัสหมุด; ที่ 32 px ดูเป็นตัวอักษรกับติ่งเล็ก |

## ข้อสรุปรอบแรก

01 ผ่านการอ่านเล็กที่สุดและเป็นฐานที่เหมาะกว่า. 04 มีไอเดียเรื่องเส้นทางไปถึงธงที่น่าต่อยอด แต่ต้องแก้สัดส่วนให้ทำงานได้เมื่อย่อ. 02 และ 03 ควรถูกตัด. ยังไม่มีแบบใดเป็น final logo.

## เกณฑ์สำหรับรอบต่อไป

- ทดสอบขาวดำที่ 16/32 px ก่อนลงสี
- รักษารูปหลักให้จำได้จากเสี้ยววินาที; รายละเอียดต้องไม่เกิดรอยชนเมื่อย่อ
- หากใช้ธง ต้องเป็นส่วนหนึ่งของเส้นทางจริง ไม่ใช่ชิ้นที่ติดทีหลัง
- เมื่อตัดสินรูปทรงแล้วจึงทำ Forest/Linen light/dark ด้วย geometry เดียวกัน
