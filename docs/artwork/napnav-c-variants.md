# NapNav — concept C variations

อัปเดต 26 กันยายน 2026; งานออกแบบ SVG สำหรับให้ผู้ใช้เลือก ยังไม่ใช่ AppIcon ใน Xcode

## จุดที่คงไว้จาก C

- หมุดสื่อปลายทาง; ตัว N ที่อยู่ภายในช่วยให้เป็น NapNav มากกว่าหมุดทั่วไป
- จุดสีที่ปลายขวาบนของ N สื่อจุดหมาย/จังหวะแจ้งเตือน
- ไม่มีตัวอักษร ฟอนต์ ภาพ raster หรือเอฟเฟกต์ที่จำเป็นต่อการอ่านรูป

## ตัวเลือก

| แบบ | สิ่งที่เปลี่ยน | บุคลิก | จุดแข็ง | จุดที่ต้องระวัง |
| --- | --- | --- | --- | --- |
| C1 Compact | หมุดกว้างและปลายสั้นขึ้น; N หนาขึ้น; ฟ้าอ่อนบนกรมท่า | สว่าง ชัด ทันสมัย | อ่านง่ายบนพื้นเข้มและใกล้เคียงแนว C ที่เลือก | อาจดูเป็นแอพแผนที่ทั่วไปหากไม่เห็น N |
| C2 Outline | หมุดเป็นเส้นหนาแทนพื้นที่ทึบ; พื้นงาช้าง | โปร่ง สุขุม | รูปทรงต่างจากไอคอนหมุดทึบ; ใช้สีเดียวได้สะดวก | รายละเอียดสองชั้นแน่นขึ้นเมื่อเล็กมาก |

| C4 Warm | หมุดสั้นและกว้าง; พื้นสีอิฐ จุดหมายฟ้า | อบอุ่น แตกต่าง | สีเด่นจากกลุ่มแอพนำทางโทนฟ้า; อ่านง่ายเมื่อย่อ | โทนอุ่นอาจไม่ตรงภาพจำของแอพนำทาง |

## ตรวจแบบ

- SVG ทั้งสี่เป็นเวกเตอร์แบบ self-contained ขนาดพิกัด 1024×1024
- ส่งออกภาพตรวจที่ 512, 64, 32 และ 16 px; ตรวจด้วยตาแล้วหมุดและ N ยังเห็นในทุกแบบ
- ส่งออกภาพสีเดียวชั่วคราว; C1/C3/C4 ยังคงหมุดทึบกับช่อง N, C2 ยังคงหมุดเส้นกับ N
- จุดสีเน้นเล็กมากเมื่ออยู่ที่ 16 px; ความหมายหลักจึงต้องอยู่ที่หมุดกับ N ไม่พึ่งจุดนั้น

## ข้อเสนอสำหรับรอบคัดเลือก

ให้ผู้ใช้เทียบ **C2** (โปร่งและแตกต่าง) กับ **C3** (ใกล้ C เดิมและอ่านเร็ว) ก่อน. ถ้าต้องการสีที่มีบุคลิกชัดกว่า ให้ลอง **C4**. หลังเลือกแล้วจึงปรับสัดส่วนด้วย optical review บน Home Screen และทำเวอร์ชันสีเดียว/reversed แบบ final
