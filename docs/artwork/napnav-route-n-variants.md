# NapNav — route N inside the pin

อัปเดต 26 กันยายน 2026; concept SVG เพื่อรับความเห็น ยังไม่ใช่ final AppIcon

## โจทย์ที่แก้จาก C1–C4

แบบก่อนใช้ N เป็น glyph ตรง ๆ จึงนิ่งและโล่งเกินไป รอบนี้ให้เส้นเดียวเดินทางจากจุดเริ่มไปจุดหมายจนเกิดรูป N โดยยังรักษา silhouette หมุดที่ผู้ใช้ชอบ

## ทางเลือกที่คัดไว้

| แบบ | ลูกเล่นของเส้นทาง | บุคลิก | ความเสี่ยงเมื่อเล็ก |
| --- | --- | --- | --- |
| R2 Curved journey | เส้น N โค้งตรงจุดเลี้ยว เหมือนเส้นทางจริงมากกว่าตัวอักษร | เป็นมิตร นุ่ม | จุดเริ่มสีอ่อนจางลงที่ 16 px |
| R3 Active route | เส้นสีมิ้นต์วิ่งทับช่วงที่เดินทางแล้วบน N สีเข้ม | มีความคืบหน้าและการเคลื่อนที่ | เส้นชั้นในหายไปเมื่อเล็ก แต่ N หลักยังชัด |
| R4 Trail | หมุดสีเข้มและเส้นทางสีอ่อนโค้งต่อเนื่องภายใน | เด่น มีลายเซ็นของแบรนด์ | ความหมายเรื่องเตือนยังอาศัยจุดปลายทางและชื่อแอพ |

R1 Waypoints เป็นการทดลองเพิ่มจุดเริ่ม/จุดจบกับ N ตรงเดิม; ตัดจาก shortlist เพราะยังไม่แก้ความรู้สึกนิ่งที่ผู้ใช้ทัก

## ตรวจแบบ

- SVG self-contained 1024×1024 ใช้ path/circle โดยไม่มี font, raster หรือ external asset
- ส่งออกและดูที่ 512, 64, 32, 16 px; R2–R4 ยังคงอ่านเป็นหมุดกับเส้นทางรูป N
- ส่งออกภาพสีเดียวชั่วคราว; silhouette ของหมุดและเส้น N ยังอยู่ แม้สีเริ่ม/ปลายและสี progress หายไป
- การตรวจนี้เป็น visual QA ของ artwork เท่านั้น ไม่ใช่การตรวจบน iPhone Home Screen, App Store หรือเครื่องหมายการค้า

## ข้อเสนอ

R4 ตรงคำขอ “ลากเส้นแทน N ด้วยเส้นทาง” มากที่สุด. R3 มีแนวคิดความคืบหน้าที่สามารถต่อยอดเป็น motion/loading ภายในแอพได้ แต่ส่วนสีมิ้นต์ไม่ควรเป็นเงื่อนไขที่ทำให้โลโก้อ่านออก. หลังผู้ใช้เลือก ให้เก็บเส้นโค้งและจุดหมายแบบ optical review แล้วทำไฟล์ SVG master และเวอร์ชันสีเดียว/reversed
