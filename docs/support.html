NapNav Support & FAQ

ศูนย์ช่วยเหลือและคำถามที่พบบ่อยสำหรับผู้ใช้งาน NapNav
1. ทำไมแอปต้องขอสิทธิ์ตำแหน่ง (Location) แบบ Always?

เพื่อให้แอปสามารถคำนวณระยะทางและส่งสัญญาณเตือนได้แม้ในขณะที่คุณล็อกหน้าจอ หรือเปิดใช้งานแอปอื่นระหว่างเดินทาง

2. สัญญาณเตือนแบบ "Use Both" ทำงานอย่างไร?

เป็นการทำงานร่วมกันระหว่างนาฬิกาปลุกเสียงเด่นชัด (AlarmKit บนอุปกรณ์ที่รองรับ) และการแจ้งเตือนแบบแบนเนอร์ ช่วยให้คุณตื่นได้แน่นอนแม้ปิดเสียงโทรศัพท์ไว้

3. แอปกินแบตเตอรี่มากไหม?

NapNav ใช้ระบบ Smart Geofencing และตรวจจับการเคลื่อนไหว เมื่อคุณยังอยู่ห่างจากจุดหมาย ระบบจะปรับการตรวจจับตำแหน่งเป็นแบบประหยัดพลังงาน และจะเริ่มตรวจสอบความแม่นยำสูงเมื่อเข้าใกล้รัศมีที่กำหนดเท่านั้น

ต้องการความช่วยเหลือเพิ่มเติมหรือพบปัญหา?

คุณสามารถส่งรายงานข้อผิดพลาดหรือข้อเสนอแนะฟีเจอร์ใหม่ได้ผ่าน GitHub Issues
