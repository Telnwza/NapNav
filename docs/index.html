แอปปลุกเตือนตามพิกัดจุดหมายสำหรับ iOS
📍
ปลุกตรงจุดตามระยะจริง (Proximity Alert) อยากให้เตือนก่อนถึง 500 ม., 1 กม. หรือ 2 กม. ก็ปรับได้ตามใจ พร้อมระบบกรองพิกัดอัจฉริยะ ป้องกันการเตือนพลาดแม้สัญญาณ GPS สวิง
⏰
ตื่นชัวร์ด้วยโหมดเตือนคู่ Use Both (AlarmKit + Notification) ผสานเสียงปลุกฉุกเฉินเข้ากับแบนเนอร์แจ้งเตือน แม้คุณจะเปิดโหมดปิดเสียงหรือโฟกัสห้ามรบกวนไว้ ก็ยังปลุกให้ตื่นได้แน่นอน
🏝️
เหลือบมองง่ายผ่าน Live Activities & Dynamic Island ก้มมองหน้าจอ Lock Screen หรือเกาะ Dynamic Island ก็รู้ระยะห่างและเวลาที่เหลือได้ทันที โดยไม่ต้องปลดล็อกเปิดจอ
🔋
ถนอมแบตเตอรี่ด้วยระบบจัดสรรพลังงาน ตอนยังอยู่ไกล ระบบจะตรวจจับตำแหน่งแบบประหยัดพลังงาน และจะเริ่มใช้ความแม่นยำสูงเมื่อเริ่มเข้าใกล้รัศมีที่คุณตั้งไว้เท่านั้น
🔒
มั่นใจเรื่องความเป็นส่วนตัว 100% (Privacy-First) พิกัดทั้งหมดคำนวณบนเครื่องของคุณเท่านั้น ไม่บันทึกประวัติการเดินทาง และไม่เคยส่งข้อมูลตำแหน่งออกไปยังเซิร์ฟเวอร์ภายนอก
