การส่งสัญญาณเตือน

โหมดเตือนคู่ Use Both

บน iOS 26 ขึ้นไป NapNav ใช้ AlarmKit เป็นระบบเสียงหลัก พร้อมการแจ้งเตือนคู่ขนาน และสลับไปใช้ระบบ Notification ตามสิทธิ์ของ iOS ทันทีหาก AlarmKit ไม่พร้อมใช้งาน

ความแม่นยำ

เลือกระยะเตือนล่วงหน้า

เลือกระยะมาตรฐาน 500 ม., 1 กม., 2 กม. หรือปรับละเอียดตามความต้องการ พร้อมระบบกรองตำแหน่งคลาดเคลื่อนชั่วคราวเพื่อลดโอกาสเตือนผิดพลาด

ความเป็นส่วนตัว

ประมวลผลบนเครื่อง 100%

ตำแหน่งของคุณถูกประมวลผลในหน่วยความจำขณะทริปทำงานเท่านั้น ไม่มีการบันทึกประวัติเส้นทาง GPS และไม่มีเซิร์ฟเวอร์หรือ SDK โฆษณาภายนอก

ข้อจำกัดการใช้งาน

การใช้งานในอุโมงค์และรถไฟฟ้าใต้ดิน

ในอุโมงค์และชั้นใต้ดิน สัญญาณดาวเทียม GPS จะถูกบดบัง แม้เครื่องจะมีสัญญาณเครือข่ายมือถือก็ไม่ได้รับประกันความแม่นยำของพิกัด หากระบบไม่ได้รับตำแหน่งที่สดใหม่ การเตือนอาจล่าช้าหรือไม่เกิดขึ้น จึงไม่ควรพึ่งพาการเตือนเมื่อนั่งรถไฟฟ้าช่วงใต้ดิน และควรสังเกตป้ายประกาศสถานีร่วมด้วยเสมอ

NapNav requires iOS 18.0 or later. AlarmKit features require iOS 26.0 or later and user authorization. Location accuracy depends on device hardware, cellular/GPS reception, and system background policies.
