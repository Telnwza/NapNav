# เส้นทาง GPS จำลอง

ไฟล์เหล่านี้ใช้กับ Xcode Simulator เพื่อทดสอบ NapNav โดยไม่ต้องเดินทางไปสถานีอโศกจริง

- `approach-destination.gpx` — เคลื่อนเข้าเขต 500 เมตรและจบด้วยสองจุดในระยะ 20 เมตร ควรแจ้งเตือนหนึ่งครั้งแล้วเปลี่ยนเป็นถึงจุดหมาย
- `pass-outside.gpx` — ผ่านด้านเหนือห่างมากกว่า 1 กิโลเมตร ไม่ควรแจ้งเตือน
- `gps-jump.gpx` — กระโดดเข้าเขตเพียง sample เดียวแล้วออก ไม่ควรแจ้งเตือน

วิธีใช้:

1. เปิด `StopAlarm.xcodeproj` แล้ว Run บน iPhone Simulator
2. เลือกอโศก ตั้งระยะ 500 เมตร แล้วเริ่มเดินทาง
3. ที่เมนู Xcode เลือก **Debug > Simulate Location** แล้วเลือกไฟล์ GPX ที่ต้องการ
4. ดูระยะทาง เวลาอัปเดต และผลการแจ้งเตือนในหน้า “กำลังเดินทาง”

> GPX พิสูจน์ flow ใน Simulator เท่านั้น การทำงานขณะล็อกหน้าจอและคุณภาพ GPS จริงต้องทดสอบบน iPhone อีกครั้ง
